# ADR-003: Placeholder-first template

- **Status:** Accepted for v0.1.
- **Decision:** Dùng dummy implementations chạy được để khóa contract/pipeline; chưa đánh giá chất
  lượng AI và không trình bày dummy score như semantic retrieval.
- **Consequence:** Team có thể thay từng adapter độc lập sau khi đã có test tích hợp.
