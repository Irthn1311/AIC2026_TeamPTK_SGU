# AIC 2026 UI prototype

## Purpose

Build a functional low-fidelity frontend prototype for three AI Challenge
HCMC 2026 retrieval tasks:

1. Textual KIS
2. Q&A
3. TRAKE

## Shared requirements

- Desktop-first, optimized for 1440 × 900.
- Grayscale low-fidelity engineering interface.
- React + TypeScript.
- Local mock data only.
- No backend or external API.
- KIS, Q&A and TRAKE must keep independent state.
- Actual Frame ID must never be confused with keyframe order.
- Ranked lists support at most 100 records.
- Validation and CSV export must work.
- Evidence workspaces must scroll independently.
- Header and bottom answer drawer remain visible.
